# منصة امتحان التحول الرقمي

## اللي اتغير عن الملف الأصلي
الملف الأصلي كان بيحاول يستخدم `window.claude.use('db')`، وده بيشتغل جوه Claude بس.
دلوقتي الصفحة (`public/index.html`) بتكلم سيرفر بسيط (`server.js`) بيخزن نتيجة كل طالب
في ملف واحد (`data/results.json`) تقدري تشوفيه وتصدّريه في أي وقت.

## هيكل المشروع
```
quiz-project/
  server.js          <- السيرفر (Express)
  package.json
  public/
    index.html        <- صفحة الامتحان (نفس التصميم، بس بتكلم السيرفر)
  data/
    results.json      <- هنا بتتخزن نتايج كل الطلاب
```

## خطوات الرفع على GitHub + Railway

1. ارفعي الفولدر ده كله (`quiz-project`) على مستودع GitHub جديد.
2. من Railway: New Project → Deploy from GitHub repo → اختاري المستودع ده.
3. Railway هيكتشف تلقائيًا إنه مشروع Node.js وهيشغل `npm install` ثم `npm start`.
4. بعد ما ينشر، هتاخدي رابط زي `https://your-app.up.railway.app` — ده رابط
   صفحة الامتحان اللي تبعتيه للطلاب.

### مهم جدًا: ثبات البيانات (Persistence)
Railway بيمسح ملفات المشروع (غير الكود) لما تعملي **Redeploy جديد**.
يعني لو هتاخدي كل النتايج بعد امتحان واحد وتصدريها فورًا، مفيش مشكلة خالص.
لكن لو عايزة النتايج تفضل محفوظة حتى لو عدّلتي في الكود بعدين، اعملي كده:
- من Railway: افتحي المشروع → Settings → Volumes → أضيفي Volume واربطيه
  بمسار `/app/data` (المسار اللي فيه `results.json`).

## إزاي تشوفي النتايج وتصدّريها
1. من صفحة الامتحان نفسها، دوسي **"عرض لوحة الصدارة بدون لعب"**.
2. هتشوفي كل الطلاب اللي دخلوا مرتبين بالنقاط.
3. تحت في نفس الشاشة فيه زرارين: **تحميل Excel** و**تحميل PDF** — دول بيصدّروا
   كل النتايج اللي ظاهرة في اللوحة.

بديل: تقدري كمان تفتحي الرابط ده مباشرة من المتصفح لتحميل Excel فورًا من غير
ما تدخلي الصفحة أصلاً:
```
https://your-app.up.railway.app/api/export/excel
```

## تشغيل تجربة على جهازك قبل الرفع (اختياري)
```
npm install
npm start
```
وبعدين افتحي `http://localhost:3000` في المتصفح.
